# TCGA Pan-Cancer Analysis of JAK3 and EPHB2

This section evaluates JAK3 and EPHB2 across TCGA cancer types.

For each cancer, the planned analysis includes, where data are available:

1. tumor versus normal expression
2. matched tumor-normal analysis
3. prevalence of aberrant expression
4. pathological stage association
5. tumor grade association
6. overall survival association

## Cancer-level analyses

| TCGA project | Cancer | Status |
|---|---|---|
| TCGA-KIRC | Kidney renal clear cell carcinoma | Main analysis completed |
| Other TCGA projects | To be analysed | Pending |

KIRC serves as the first cancer-specific analysis and methodological template for the subsequent pan-cancer evaluation.
