# GSE141656

JAK3 post-rest validation in human beta-glucan-trained macrophages.

## Design

- Human monocytes
- Beta-glucan training for 24 h
- Five-day differentiation/rest
- Day6 transcriptome
- Three donors: A, B, C
- Primary analysis uses non-Mtb samples only

## JAK3 result

Day6 beta-glucan vs Day6 RPMI:

- logFC = -0.105
- 95% CI = -1.600 to 1.390
- P = 0.834
- FDR = 0.940

Donor direction:

- A positive
- B negative
- C slightly positive

## Classification

No evidence of persistent JAK3 deregulation after beta-glucan training.
