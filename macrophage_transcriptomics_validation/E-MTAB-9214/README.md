# E-MTAB-9214

JAK3 persistence analysis in house-dust-mite-trained human monocyte-derived macrophages.

## Design

- Homo sapiens
- Primary human monocyte-derived macrophages
- House dust mite exposure
- 24 h training
- Washout/rest phase
- Late resting macrophage RNA-seq before secondary challenge
- Three HDM-trained and three control samples

## Source analysis

Processed DESeq2 table:

set2_ctr-VS-D7HDM.txt

The deposited contrast is control vs D7HDM.

## JAK3 result

Original deposited result:

- control vs D7HDM log2FC = -1.700
- P = 9.96e-10
- FDR = 6.44e-07

Standardized direction used in the cross-dataset analysis:

- D7HDM vs control log2FC = +1.700

Normalized JAK3 expression:

- D7HDM: 107.916, 85.107, 104.023
- Control: 33.024, 24.440, 28.045

All three trained samples showed higher JAK3 expression.

## Classification

Strong significant persistent JAK3 upregulation after HDM training.
