# GSE58310

Human primary monocyte/macrophage stimulus-washout transcriptomic validation.

## Design

- 24 h initial exposure
- RPMI control
- LPS
- beta-glucan
- washout
- Day 6 transcriptomic measurement
- 4 independent donors

## Primary JAK3 comparisons

- Day6 LPS vs Day6 RPMI
- Day6 beta-glucan vs Day6 RPMI

## Current interpretation

- LPS: heterogeneous / uncertain across donors
- beta-glucan: consistent negative post-washout JAK3 shift across all four donors
