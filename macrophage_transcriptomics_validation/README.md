# JAK3 Cross-Dataset Macrophage Transcriptomics Validation

Objective:

To determine how frequently JAK3 remains transcriptionally deregulated after
stimulus removal / washout / recovery in independent monocyte and macrophage
transcriptomic datasets.

## Inclusion focus

- monocyte/macrophage systems
- transcriptomic profiling
- defined initial stimulus
- washout/rest/recovery phase
- later post-stimulus RNA measurement
- matched late control where possible
- biological replicates preferred

## Dataset folders

Each eligible dataset is stored in a separate subfolder containing:

- README.md
- scripts/
- results/
- figures/
